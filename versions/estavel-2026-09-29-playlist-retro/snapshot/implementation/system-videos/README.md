# Vídeos da versão estável atual

Uma única reprodução 720x720 por clipe; 60fps codificados, velocidade 1x e loop. Não equivale a 60fps sustentados no aparelho. Visíveis têm prioridade, até quatro anteriores e dois seguintes preparados conforme capacidade, limite de 12 players. Um quadro GPU é retido por clipe visitado para o retorno, sem foto ou segunda camada.

27 vídeos cobrem 29 de 36 plataformas ativas. Faltam Atari 7800, Game Gear, Game Boy Color, Jaguar, PC Engine, PC Engine CD e SuperGrafx. O mapa ampliado também registra Sufami. Não inventar substitutos.

Fontes privadas exclusivamente da pasta caratulas indicada no manifesto. MP4s ficam locais em system-videos/assets/. Leia RESTAURACAO.md da versão; build_videos.py usa o APK camera-traseira como BASE e gera a versão atual com playlist. A tag mencionada em build-result.json identifica essa base anterior.
