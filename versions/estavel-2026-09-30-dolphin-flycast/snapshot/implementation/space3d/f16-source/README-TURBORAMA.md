## Derivative asset

`f16-exterior-original.glb` is a static conversion, generated by `convert_exterior.py` on 2026-09-29. The original AC3D files and texture images are preserved unmodified under `Models/`. The conversion includes the exterior, single Pratt & Whitney nozzle, visible upper pilot, cockpit shell and seat. It omits landing gear, dense invisible cockpit parts, old flat exhaust effects and optional military logos. It closes the front gear door and recalculates smooth normals using each AC3D surface crease. See `conversion-report.json` for exact object counts, selections and bounding boxes.

The derivative visual asset and its conversion source retain GPL-2.0-or-later. ## Integration

- 29,937 vertices; 39,802 triangles; 200 primitive/material groups.
- Coordinate system: +Y up, +Z nose/forward, +X right. AC3D mapping `(z, y, -x)/7.5`, retaining original longitudinal origin.
- UVs converted from AC3D bottom origin to glTF top origin `(u, 1-v)`, including original texrep/texoff. Some nozzle/cockpit UVs wrap; textures use REPEAT. Preserve repetition when atlasing.
- Material image names are relative source paths and may contain `..`; resolve against this directory.
- Engine centerline `(0,0)` in XY, direction `(0,0,-1)`. Physical exit is Z=-0.72181064, radius0.0428..0.04389. See `nozzle-alignment.json`.
- `preview_exterior.py` renders original materials and confirms CCW exterior winding. It is a geometry inspection, not the final Turborama paint/lighting.
- Rebuild with Python + NumPy: `python convert_exterior.py`. NumPy is loaded from the existing adjacent `../python-libs` dependency directory.

The XML files are retained as source references for original visual placement only; do not execute their simulation scripts or include them as application behavior.
