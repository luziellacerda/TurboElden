# Evidência herdada da base R112

Estes três arquivos foram copiados com a árvore completa da R112 e são mantidos
somente como referência da base. Eles **não** descrevem a candidata R113:

- `package.json`: pacote final R112;
- `structural-checks.json`: checagens estruturais R112;
- `bytecode-hooks.txt`: inspeção de bytecode R112.

A compilação da R113 grava suas próprias evidências em `evidence/package.json`
e `evidence/frontend/`. A receita falha se o APK base não tiver SHA-256
`17e2748766a4fe82a043406e392ff3bd4c0b7a55d03e353b7925ebfbdc3f9775`.
